# Calculator

Консольный калькулятор на C++ с динамически загружаемыми DLL-плагинами.

## Сборка

Требуются CMake и компилятор с поддержкой C++20. В PowerShell из корня проекта выполните:

```powershell
cmake -S . -B build
cmake --build build --config Release
```

Исполняемый файл и плагины будут созданы в каталоге `build/bin`.

## Запуск

Для интерактивного ввода запустите приложение:

```powershell
.\build\bin\calc.exe
```
Введите выражение в новой строке.

DLL-плагины должны появиться в каталоге `build/bin/plugins` рядом с приложением.
